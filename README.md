# Kortemme Lab structural explorer

Interactive comparison of the representative NMR models for apo I89 state 1 (PDB 9CIG) and state 2 (PDB 9CID), inspired by Guo et al., *Science* 2025.

The site is a personal exploratory analysis by Cathy Liu. It uses public PDB coordinates and clearly distinguishes descriptive structure comparison from simulated dynamics.
